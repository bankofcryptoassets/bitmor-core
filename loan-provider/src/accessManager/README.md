# Access Manager for Bitmor Protocol

This is repo contains the Access Manager contract, with the implementation based on [OpenZeppelin's Access Manager](https://docs.openzeppelin.com/contracts/5.x/access-control#access-management).

![alt text](https://docs.openzeppelin.com/access-manager.svg)

This access manager will control the following CONTRACTS in Bitmor with the respective ROLES (`roleId`) and `expectedDelay`. Roles with multiple delay requirements have been split into FAST and SLOW variants. Slow roles append '0' to the original role ID and have corresponding guardian roles starting with '9'.
